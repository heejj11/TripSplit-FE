# TripSplit Frontend Starter

Next.js 14 + TypeScript + TanStack Query + Zustand + Tailwind CSS 스타터 템플릿

## 시작하기

```bash
npm install
cp .env.example .env.local
npm run dev
```

## 폴더 구조

```
src/
├── app/              # Next.js App Router
├── components/ui/    # UI 컴포넌트
├── hooks/            # 공통 훅
├── lib/              # 유틸, API 클라이언트
├── stores/           # Zustand 스토어
└── types/            # 타입 정의
```

## 스택

- Next.js 14 (App Router)
- TypeScript
- TanStack Query
- Zustand
- Tailwind CSS
- Axios
